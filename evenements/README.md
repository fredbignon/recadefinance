# Format d'un événement

Un fichier Markdown par événement, nommé AAAA-MM-JJ-titre-court.md (la date du nom est celle du début). Le texte sous l'en-tête décrit l'événement et son programme, en quelques paragraphes.

Champs de l'en-tête :

- title : nom exact de l'événement, avec l'édition.
- date et date_fin : AAAA-MM-JJ (date_fin peut être omise pour un événement d'un jour).
- ville, pays, lieu : où se tient l'événement (lieu = salle ou hôtel).
- organisateur : le nom de l'organisateur.
- themes : liste de thèmes, par exemple ["Finance", "Fintech", "Intelligence artificielle"].
- acces : qui peut venir (public, professionnels, sur invitation).
- tarif : tarif si publié, sinon "Non communiqué par les organisateurs".
- statut : "confirmé" ou "à confirmer". Avec "à confirmer", la fiche et l'agenda signalent que les dates ne sont pas sûres.
- lien : adresse du site officiel de l'événement.
- accroche : une phrase d'environ 140 caractères, affichée dans l'agenda.
- verifie_le : date à laquelle vous avez vérifié les informations auprès de la source.
- source : d'où viennent les informations.

Règles de la rubrique :

- N'inscrire un événement que s'il a une source officielle (site de l'organisateur ou communiqué).
- Vérifier les informations avant publication, et à nouveau une semaine avant la date.
- Ne copier ni logos ni photos de l'organisateur sans son accord.
- Un événement passé migre tout seul vers « Événements passés » à la date de fin.
